# PixelPipe design system

## Goal

Make long-running video encoding feel calm, clear, and lightly playful. The app
borrows the energy of classic platform games without copying recognizable game
characters, logos, blocks, or other protected assets.

## Layout

- A 172 px hero banner communicates readiness and system status.
- The flexible left surface is the encode queue and primary task area.
- A 315–360 px right rail contains progressive settings.
- The bottom bar keeps progress and run controls visible at all times.

## Type

- Windows system stack: Segoe UI Variable, then Segoe UI.
- Titles are bold and compact; body copy stays at 10–11 pt.
- Technical numbers use concise labels such as 29.97, 1080p, and H.264.

## Color tokens

- Canvas: `#071426`
- Surface: `#0D1D34`
- Raised input: `#09182B`
- Border: `#1D3656`
- Primary text: `#EAF3FF`
- Muted text: `#91A7C2`
- Focus/active blue: `#35B9FF`
- Primary action gold: `#F3BC45`
- Success mint: `#72E3B1`
- Error coral: `#FF9D8D`

## Interaction rules

- Gold is reserved for the primary action and group headings.
- Blue communicates active work, focus, and drop targets.
- Destructive actions use muted coral rather than saturated red.
- Encoding controls remain visible and disabled states remain legible.
- Decorative imagery never competes with the queue or settings.

## Assets

- `assets/app_icon.png`: original film-through-pipeline mark with transparency.
- `assets/app_icon.ico`: multi-resolution Windows icon.
- `assets/splash.png`: original wide pipeline artwork used in the app header.
